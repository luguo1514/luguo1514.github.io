这里是我的个人主页：**作品**放我做的东西，**随笔**存我的想法与记录。

以后想写新的随笔，只需在 GitHub 仓库的 `_posts` 文件夹里新建一个文件，命名为：

```
2026-11-01-标题.md
```

文件开头写这样的信息（front matter），下面是正文：

```yaml
---
layout: post
title: 文章标题
date: 2026-11-01
tags: [随笔]
---
正文写在这里，支持 Markdown 格式。
```

保存并提交后，网站大约一分钟内自动更新公开。
